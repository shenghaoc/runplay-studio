# Training-load kernel design

The calculator still calls the same Core-facing adapter. Core validates and converts intervals, checks cancellation before and after the kernel, translates errors, and retains its output-contract checks. The engine only borrows the sample span and returns a fixed-size summary with five inline zone buckets. All floating-point expressions mirror the C++ order, with exponential evaluation using the same platform C library. Both sides of the differential marshal raw samples inside the Core test target; no parity bridge remains in production.
