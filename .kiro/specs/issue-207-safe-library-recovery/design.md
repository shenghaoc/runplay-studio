# Design

The file store classifies only a missing path as missing and propagates other read errors. The actor separates available rows from referenced rows. Selection may fall back in memory without changing the saved selection; manifest organization repair works against the original ordered references. The package-internal load result carries IDs to the Studio warning and does not change the data on disk.

Before replacing a snapshot, round-trip the existing representation and check that every original object field, array element, and scalar has a representable counterpart. Missing fields in the original may acquire defaults. Keep existing lossy read behavior without letting it authorize a rewrite. Staged promotion only creates new final destinations.

Startup cleans the reserved batch directories in .staging when the actor has no active batch. Unreferenced final snapshots are kept because an absent reference does not prove they are debris.
