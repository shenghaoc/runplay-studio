# Durable Learnings

`.jules/` contains curated, reusable learnings discovered during completed work.
It is not the canonical instruction source: [AGENTS.md](../AGENTS.md) always
wins.

- `bolt.md` covers performance and scalability.
- `palette.md` covers accessibility and interaction design.
- `sentinel.md` covers security and data safety.

Add an entry only for a concrete reusable finding. Include the affected
subsystem and the preventive action. Consolidate duplicate findings instead of
appending similar entries indefinitely.

Never store task or branch status, latest commit hashes, private workout data,
secrets, speculative advice, or copied sections from `AGENTS.md` here.
