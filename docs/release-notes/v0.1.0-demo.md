# RunPlay Studio v0.1.0-demo

First public demo release of RunPlay Studio — a native macOS post-run route
replay and analysis app.

## Headline Features

- **Apple Maps 2D/3D route replay** — One SwiftUI map with an in-map camera
  toggle, realistic elevation, route overlays, and replay markers
- **Synchronized replay** — Map, charts, metrics, and split table all stay
  in sync with the timeline; chart click/drag-to-seek
- **Segment detection** — Automatic identification of fastest 400m, fastest 1km,
  slowest 1km, biggest climb, and biggest descent
- **Route comparison** — Side-by-side comparison of two runs with summary deltas,
  per-split table, pace chart, and a shared 2D/3D MapKit overlay
- **Comparison distance slider** — Scrub along common route distance with
  interpolated markers and elapsed time/pace delta readout
- **Export** — Local JSON summary, splits CSV, segments CSV, combined CSV, and
  PNG summary card (1200×1600)
- **Local-only privacy** — No account, no cloud, no telemetry, no analytics, no
  AI API; all workout data stays on your Mac

## Supported Import Formats

| Format | Status |
|--------|--------|
| JSON   | Full support (native format) |
| GPX    | Track support with HR/cadence extensions |
| TCX    | Full support with laps, HR, cadence, distance |
| FIT    | Running-session support with CRC validation, compressed timestamps, pause boundaries, GPS, altitude, speed, HR, and cadence |

## Supported Export Formats

- JSON summary
- Splits CSV
- Segments CSV
- Combined CSV
- PNG summary card

## Privacy Statement

RunPlay Studio is a local-only application. No workout data leaves your Mac.
The only network activity is Apple MapKit loading content for the flat and
pitched map presentations.
No cloud sync, no accounts, no telemetry, no analytics, no AI APIs.

## Known Limitations

- Comparison is distance-aligned only — no dynamic time warping or route matching
- FIT import selects one unambiguous GPS-bearing running session; batch and
  non-running session import are not supported
- No HealthKit integration
- No cloud sync, accounts, or web interface
- macOS only (requires SwiftUI and MapKit)
- PNG export requires GUI context (`ImageRenderer`)

## Quick Start

```bash
git clone https://github.com/shenghaoc/runplay-studio.git
cd runplay-studio
open Package.swift
```

Select the **RunPlayStudio** scheme, choose **My Mac**, press **⌘R**.

See [docs/demo-script.md](../demo-script.md) for a 3–5 minute walkthrough.
